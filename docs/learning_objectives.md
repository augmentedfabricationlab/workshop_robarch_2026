At workshop completion, participants will be able to:

- **Turn observations into a structured model.** Translate text, images, and scans of an existing structure into a graph-based Assembly Model of components, connections, and damage states.
- **Prompt for action, not description.** Formulate prompts with defined roles, repair goals, and constraints (tools, materials, robotic capability) that yield an Action Model.
- **Generate and compare repair strategies.** Produce more than one procedural repair plan for the same damage, with the intervention steps made explicit.
- **Plan and execute robot-enabled actions.** Set up scanning, marking, stabilisation, and milling, accounting for kinematics, end-effectors, and workspace.
- **Test and refine by making.** Apply the scan-after-cut loop to derive fit, and use the discrepancy between model and material as design information.
